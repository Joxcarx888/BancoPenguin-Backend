## 📝 Descripción

Este repositorio contiene el backend que maneja las **acciones de los usuarios** y **administradores** dentro del sistema. Las funcionalidades incluyen:

- **Gestión de usuarios** por parte de los administradores.
- **Actualización de la información personal** de los usuarios.
- **Canje de recompensas** utilizando puntos de las cuentas del usuario, con validación de puntos disponibles para el canje.
- Los **administradores** pueden ver todas las recompensas canjeadas por cualquier usuario, mientras que los **usuarios** solo pueden ver las recompensas que ellos mismos han canjeado.

Todas las funcionalidades están **finalizadas y funcionando correctamente**.
